#⚛️ Atomica: Stonefall

Knowledge is progression.

Atomica: Stonefall is an indie 2D pixel-art science-survival game about rediscovering knowledge, experimenting with the world, and rebuilding civilization.

🔬 About the Game

Explore a world shaped by humanity’s collapse. Gather resources, craft tools, experiment with scientific principles, and discover how knowledge can change what is possible.

Science isn’t just part of the setting — it’s part of the gameplay.

🛠️ Development

Atomica: Stonefall is currently in development.

* 🎨 Original pixel art
* 🧪 Science-inspired crafting and progression
* 🌎 Exploration and survival
* 📖 A mysterious world with a deeper story to uncover

This project is independently developed, with its art, music, sound effects, and code created as part of the development process.
